# OfflineStepik

OfflineStepik состоит из двух частей: расширение Chrome/Edge сохраняет доступные материалы курса Stepik в файл `.stepikpack`, а Android-приложение открывает этот файл без подключения к интернету.

Используйте сбор только для курсов, на копирование которых у вас есть разрешение. Программа сохраняет отображаемые материалы и не извлекает скрытые ответы или серверные проверки.

## Что нужно

- Chrome или Microsoft Edge для расширения.
- Android Studio и Android SDK 35, чтобы собрать приложение. Минимальная версия Android — 10 (API 29).
- Node.js, чтобы запускать тесты расширения.

## 1. Установить расширение на ПК

1. Скачайте или клонируйте репозиторий.
2. Откройте `chrome://extensions` в Chrome или `edge://extensions` в Edge.
3. Включите режим разработчика и нажмите **Загрузить распакованное расширение**.
4. Выберите папку `PC` в этом репозитории.
5. Войдите в Stepik в браузере и откройте первый шаг нужного курса.
6. Нажмите значок OfflineStepik и выберите **Начать сбор с текущей страницы**. Во время сбора можно приостановить или остановить процесс.
7. Когда сбор завершится, нажмите **Экспортировать .stepikpack**. Браузер сохранит файл курса.

Расширение читает открытые страницы Stepik и сохраняет состояние локально в браузере. Видео не включаются в пакет; задания, проверяемые сервером, доступны как материалы для чтения и черновика.

Подробности и устранение проблем: [PC/README.md](PC/README.md).

## 2. Открыть курс на Android

1. Передайте `.stepikpack` на телефон.
2. Установите OfflineStepik: откройте файл в приложении, собранном по инструкции ниже, или в Android Studio откройте папку `Android` и запустите приложение на устройстве.
3. В приложении выберите импорт `.stepikpack` и укажите файл.
4. Откройте курс в библиотеке. Импортированный курс хранится во внутренней памяти приложения и доступен после перезапуска без сети.

Также можно собрать APK из Android Studio: откройте папку `Android` и выберите **Build → Build APK(s)**. APK для отладки появится в `Android/app/build/outputs/apk/debug/app-debug.apk`. Из командной строки с установленным Gradle выполните:

```powershell
gradle -p Android assembleDebug
```

Подробности импорта: [Android/README.md](Android/README.md).

## Запуск тестов

Из корневой папки репозитория:

```powershell
node --test PC/test/pack.test.mjs
```
