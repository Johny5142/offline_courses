# OfflineStepik Android

Личное Android-приложение для чтения файлов `.stepikpack`, экспортированных расширением из папки `PC`. Формат v2 переносит кликабельное оглавление курса вместе с теорией и заданиями; пакеты v1 также импортируются.

Целевой диапазон — Android 10 и новее. `minSdk = 29`; приложение не запрашивает доступ к интернету. Импорт выполняется системным выбором файлов, затем пакет разбирается локально. Теория отображается в отключённом от сети WebView, задания доступны для чтения. У каждого курса своя папка во внутренней библиотеке; повторный импорт того же курса обновляет его папку, а другой курс добавляется отдельно.

## Сборка APK

Открой папку `Android` в Android Studio с установленным Android SDK 35 и выполни `Build > Build APK(s)`. Либо из терминала с установленным Gradle:

```powershell
gradle assembleDebug
```

APK появится в `app/build/outputs/apk/debug/app-debug.apk`. Его можно установить на личные устройства Android 10 и 17.

## Импорт

1. Передай на телефон файл с расширением `.stepikpack`.
2. Открой его через OfflineStepik или запусти приложение и нажми «Импортировать».
3. Выбери файл и открой шаг курса.

Импортированный пакет сохраняется во внутренней папке `files/courses/<название-и-id>/course.stepikpack` и открывается после перезапуска без повторного выбора файла. Оглавление группирует разделы, уроки и шаги. Несобранные шаги видны, но отключены; сохранённые пункты открывают офлайн-читалку. Кнопка «Удалить» в библиотеке удаляет курс после подтверждения.
