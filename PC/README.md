# OfflineStepik PC

Локальное расширение Chrome/Edge. Оно работает только с текущей вкладкой `stepik.org`, читает отображённый DOM, идёт по ссылкам «Следующий шаг/урок» и экспортирует JSON-пакет v2 с расширением `.stepikpack`. В пакет входят снимки оглавления: разделы, уроки и шаги текущего урока.

## Запуск

1. Открой `chrome://extensions` или `edge://extensions`.
2. Включи режим разработчика.
3. Нажми «Загрузить распакованное расширение» и выбери эту папку `PC`.
4. Войди в Stepik обычным способом и открой первый нужный шаг курса.
5. Открой OfflineStepik и нажми «Начать сбор с текущей страницы».
6. После завершения нажми «Экспортировать .stepikpack».

Кнопка «Очистить сохранённое» удаляет локальный сбор и оглавление из расширения после подтверждения. Экспортированные файлы на диске она не удаляет.

После обновления расширения нажми его значок перезагрузки на странице расширений и обнови вкладку курса, чтобы в ней загрузилась новая версия скрипта. Если браузер не разрешит подключение после обновления вкладки, повтори запуск.

Это первый рабочий прототип. Он сохраняет отображённую теорию и условия заданий; задания с серверной проверкой экспортируются как материалы для чтения и черновика. Скрипты страниц удаляются, видео не включаются.

Изображения с `ucarecdn.stepik.net` сохраняются в пакет через фоновый процесс расширения. Chrome может запросить доступ к этому CDN.

Данные обхода хранятся в `chrome.storage.local`, поэтому закрытие popup не прерывает процесс. При закрытии браузера продолжение запускается вручную.

Сбор ждёт готовности контейнера урока, а при поздней загрузке навигации ждёт её появления до восьми секунд. Шаги в текущем уроке упорядочиваются по номеру, затем расширение проходит ссылки следующих уроков; повтор уже посещённой ссылки не помечает курс завершённым. Для перехода используются ссылка, подписанная кнопка или ячейка полосы прогресса. Если переход не распознан, статус покажет диагностические счётчики.

Оглавление берётся из ссылок меню курса, а полоса шагов — отдельно из ссылок текущего урока. Переход на следующий урок открывает его `/step/1`; сборщик ждёт настоящего контейнера урока и игнорирует экран оболочки по адресу `/lesson/ID`. Это предотвращает пропуски первого шага. ID шага включает ID урока, поэтому одноимённые шаги из разных уроков не склеиваются. Повторный сбор заменяет старую оболочку загрузки настоящим содержимым, сохраняя место шага в списке.

Если после обновления расширения состояние показывает «Завершено» и один шаг, нажмите «Начать сбор» ещё раз: завершённый запуск будет сброшен и начнётся с открытой страницы. Если расширение остановилось на паузе, перейдите к следующему шагу курса вручную и нажмите «Продолжить» — ранее собранные шаги сохранятся.
